# 관리자 페이지 사용법

쇼핑몰을 운영하는 분을 위한 안내입니다. 개발 지식은 필요 없습니다.

## 들어가기

1. 사이트 주소 뒤에 `/admin`을 붙여 접속합니다(예: `https://dtive-astiger.com/admin`).
2. 관리자로 지정된 계정으로 로그인되어 있어야 합니다. 일반 회원 계정이면 홈으로 돌아갑니다. 관리자 지정은 개발 담당자가 합니다([HANDOVER](HANDOVER.md) 2.2절 11단계).
3. **2단계 인증**: 관리자는 로그인 후 휴대폰 인증 앱의 6자리 코드를 한 번 더 입력해야 들어갈 수 있습니다.
   - **처음 한 번**: "인증 앱 등록" 화면이 나옵니다. 휴대폰에 인증 앱(Google Authenticator, Microsoft Authenticator 등)을 설치하고, 앱에서 QR 코드를 스캔합니다(스캔이 안 되면 화면의 "키"를 앱에 직접 입력). 앱에 나온 6자리 코드를 입력하고 **등록**을 누릅니다.
   - **그다음부터**: "2단계 인증" 화면에서 앱에 지금 나온 6자리 코드를 입력하고 **확인**을 누릅니다. 코드는 30초마다 바뀝니다.
   - "코드가 올바르지 않습니다"가 나오면 앱에 새로 나온 코드로 다시 입력하세요. 휴대폰 시간이 자동으로 맞춰져 있어야 합니다.
   - **휴대폰을 잃어버렸거나 바꿨을 때**: 코드를 받을 수 없으니 개발 담당자에게 연락하세요. 개발 담당자가 본인 확인 후 등록된 인증 앱을 지우면(아래 SQL, [HANDOVER](HANDOVER.md) 3절 "관리자 인증 앱 분실·교체"), 다음 로그인 때 등록 화면이 다시 나옵니다.
     ```sql
     delete from auth.mfa_factors where user_id = (select id from auth.users where email = '관리자 이메일');
     delete from auth.sessions    where user_id = (select id from auth.users where email = '관리자 이메일');
     ```
4. 왼쪽 메뉴(모바일은 상단 메뉴 버튼): **대시보드 · 주문 · 상품 · 카테고리 · 회원 · 홈 화면 · 설정**.

공용 PC에서는 쓰지 말고, 쓰고 나면 로그아웃하세요. 인증 앱이 든 휴대폰은 잠금을 걸어 두세요.

## 처음 한 번: 설정

**설정** 화면에서 입금 받을 **은행·계좌번호·예금주**를 입력하고 저장합니다. 계좌가 비어 있으면 고객이 주문할 수 없습니다.

같은 화면에서 바꿀 수 있는 것:

- **입금 기한(시간)**: 주문 후 이 시간 안에 입금이 없으면 주문이 자동 취소되고 재고가 돌아옵니다. 기본 48시간.
- **배송비(원)**, **무료배송 기준(원)**: 상품 금액이 기준 이상이면 배송비 0원. 비우면 무료배송 없음.

바꾼 값은 이후 주문부터 적용됩니다. 이미 들어온 주문은 주문할 때의 계좌·금액이 그대로 안내됩니다. 이용약관·FAQ·배송 안내의 배송비·입금 기한 문구도 자동으로 바뀝니다.

화면 아래 **변경 기록**에는 누가 언제 상품·주문·설정을 바꿨는지 남습니다.

## 매일 하는 일: 주문 처리

**주문** 화면 위쪽 탭으로 상태별 주문을 봅니다. 주문번호·수령인으로 검색하고 기간을 정할 수 있습니다. 고객이 취소를 요청한 주문에는 "취소 요청" 표시가 붙습니다.

주문 상태는 아래 순서로만 넘어갑니다. 화면에는 지금 누를 수 있는 버튼만 보입니다.

```
입금 대기 → 입금 확인 → 상품 준비중 → 배송중 → 배송 완료
     ↘ 취소           ↘ 취소 → 환불 완료
```

1. **입금 확인**: 은행 앱에서 입금 내역을 보고, "입금 대기" 주문의 **입금자명·금액**과 맞춰 봅니다. 맞으면 주문 상세에서 **입금 확인**. 입금자명이 다르면 고객이 보낸 문의 메일과 주문번호로 확인합니다.
2. **상품 준비중**: 포장을 시작할 때 누릅니다(건너뛰고 바로 송장을 넣어도 됩니다).
3. **송장 입력**: 택배사를 목록에서 고르고 송장번호를 넣어 저장하면 **배송중**이 됩니다. 고객 주문 화면에 배송 조회 링크가 생깁니다. 송장번호를 잘못 넣었으면 같은 곳에서 다시 저장하면 고쳐집니다.
4. **배송 완료**: 택배 조회로 도착을 확인하면 누릅니다.

### 취소와 환불

- **입금 전 주문**: 고객이 마이페이지에서 직접 취소할 수 있고, 기한이 지나면 자동 취소됩니다. 관리자가 취소할 때는 **주문 취소**.
- **입금 후 발송 전 주문**: 고객은 "취소 요청"만 할 수 있습니다. 요청을 확인하면 **주문 취소**를 누르고, 메모에 **환불 계좌와 금액**을 적습니다(필수, 고객에게 보이지 않음). 고객 화면의 취소 사유는 고객이 적은 요청 사유로 남습니다. 재고는 자동으로 돌아옵니다.
- 은행에서 환불 이체를 마치면 같은 주문에서 **환불 완료**를 누릅니다.
- **발송 후 반품**: 고객이 이메일로 신청합니다. 상품이 돌아오면 확인 후 3영업일 안에 환불 이체하고, 주문 상세의 관리자 메모에 처리 내용을 적습니다(관리자 메모는 고객에게 보이지 않음). 배송 완료된 주문은 상태를 바꿀 수 없고, 돌아온 상품의 재고는 상품 화면에서 직접 늘립니다.

### 입금 기한이 지난 주문

10분마다 자동으로 취소됩니다. 대시보드의 **만료 주문 정리** 버튼을 누르면 바로 정리됩니다(자동 취소가 동작하지 않는 환경에서는 하루 몇 번 눌러 주세요).

## 대시보드

입금 대기·입금 확인·상품 준비중·배송중 건수, 오늘 주문, 최근 30일 매출, 재고 3개 이하 옵션, 최근 주문이 보입니다. 하루를 시작할 때 여기서 처리할 일을 확인하세요.

## 상품

- **상품 목록**: 이름 검색, 상태(임시저장/판매중/보관) 필터.
- **상품 추가** / 상품을 눌러 수정:
  1. 상품명, 카테고리, 판매가, 정가(할인 전 가격, 할인할 때만), 상세 설명, 소재, 세탁 방법. 주소(슬러그)는 자동으로 만들어집니다.
  2. **이미지**: JPEG·PNG·WebP, 10MB 이하. 올리면 자동으로 크기를 줄여 저장합니다. 끌어서 순서를 바꾸고(첫 번째가 대표 사진), 색상을 지정하면 고객이 그 색을 고를 때 해당 사진이 보입니다. 사진 설명(대체 텍스트)은 화면을 읽어 주는 프로그램이 사용하니 짧게 적어 주세요.
  3. **옵션**: 색상과 사이즈를 정하면 조합마다 재고를 입력하는 줄이 생깁니다. 재고 0은 "품절"로 표시됩니다. 화면을 연 뒤 주문 등으로 재고가 바뀌었는데 재고를 고쳐 저장하면 "그사이 재고가 바뀌었습니다"가 뜨고 아무것도 저장되지 않습니다. **다시 불러오기**를 눌러 지금 재고를 보고 다시 입력하세요. 재고를 고치지 않은 저장은 주문으로 줄어든 재고를 그대로 둡니다.
  4. **상태**: 임시저장(고객에게 안 보임) → 준비되면 **판매중**. 판매를 끝낼 때는 **보관**.
  5. 저장. 오류가 나면 상품을 다시 열어 내용이 다 들어갔는지 확인 후 다시 저장하세요.
- 한 번이라도 주문된 상품은 삭제할 수 없고 **보관**으로 바꿉니다.

## 카테고리

2단계(예: WOMEN › 아우터)로 관리합니다. 추가, 이름·주소 변경, 위/아래로 순서 변경, 표시 여부, 대표 이미지(메뉴에 보이는 사진)를 정합니다. 최상위 카테고리는 사이트 상단 메뉴가 되며 최대 5개까지 보입니다. 카테고리를 지우면 그 안의 상품은 "미분류"가 되어 전체 상품 목록에만 보입니다.

## 홈 화면

홈에 보이는 구역(섹션)을 위에서부터 순서대로 관리합니다.

- **메인 배너**: 큰 사진 한 장 + 제목 + 링크
- **2단 배너**: 사진 두 장을 나란히
- **상품 모음**: 카테고리 또는 직접 고른 상품 최대 8개
- **룩북**: 사진 여러 장과 설명 (룩북 페이지에도 보임)

섹션마다 추가·수정·순서 변경·표시/숨김을 할 수 있습니다. 첫 섹션이 메인 배너면 홈 상단 메뉴가 사진 위에 투명하게 겹칩니다. 링크 경로는 사이트 안 주소(예: `/shop/women`)를 적습니다.

## 회원

가입한 회원 목록(이름·이메일·전화·가입일·주문 수·마케팅 수신 동의)을 보고 검색합니다. 회원을 누르면 그 회원의 주문을 볼 수 있습니다. 회원 정보 수정, 관리자 지정, 강제 탈퇴는 이 화면에서 하지 않습니다(필요하면 개발 담당자에게).

회원 정보는 개인정보입니다. 주문 처리 외의 용도로 쓰거나 내려받아 보관하지 마세요. 마케팅 메일은 "마케팅 수신 동의"한 회원에게만 보낼 수 있습니다.

## 자주 묻는 상황

| 상황                                         | 할 일                                                                                 |
| -------------------------------------------- | ------------------------------------------------------------------------------------- |
| 고객이 "주문을 받을 수 없다"는 메시지를 봤다 | 설정의 입금 계좌가 비어 있는지 확인                                                   |
| 입금했다는데 주문이 취소됐다                 | 기한이 지나 자동 취소된 주문. 고객에게 다시 주문을 부탁하고, 이미 받은 돈은 환불 이체 |
| 입금 금액이 주문 금액과 다르다               | 고객에게 연락해 차액 입금 또는 환불                                                   |
| 버튼이 없다                                  | 그 상태에서는 할 수 없는 작업(위 순서도 참고)                                         |
| "권한이 없습니다"                            | 관리자 계정이 아님. 개발 담당자에게 문의                                              |
| 저장 후 화면이 바뀌지 않는다                 | 새로고침. 계속되면 오류 메시지를 캡처해 개발 담당자에게                               |
